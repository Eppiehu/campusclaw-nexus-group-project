# 接口与数据契约（规划版）

本文固定开发前的语义与边界；拟定 URL 见 [API 清单](api-contract.md)，实体与约束见 [数据模型](data-model.md)。最终字段和数据库迁移需在对应实现变更中细化并评审。

## 1. 核心实体

| 实体 | 必要关联与约束 |
| --- | --- |
| User、Class、Membership | 用户身份、角色、任教/就读班级；不能仅凭请求参数授予班级权限 |
| Material、MaterialVersion、Chunk | 材料归属班级；版本不可变；切片保留文件、页码/段落、版本和索引状态 |
| App、PromptTemplate、SkillBinding、ToolBinding | AI 应用的配置版本、启停状态和允许的工具集合 |
| Conversation、Message、Citation、ToolCall | 会话归属用户与班级；引用锚定片段快照；工具调用 ID、参数摘要和结果状态成对保存 |
| KnowledgeGap、GapEvidence、GapReview | 候选缺口按班级归并，保留问题、来源、教师审核与回补状态 |
| AssignmentTemplate、AssignmentInstance、Submission、GradeReview | 每名学生独立实例、服务端答案、提交、AI 初评和教师最终分分别存储 |
| WeeklyReport、ReportFact、ReportReview | 统计事实与 AI 文本分离，发布版本与教师审核记录可追溯 |
| Job、AuditEvent | 后台任务状态、重试次数、错误信息及关键权限操作审计 |

## 2. 统一接口行为

- 所有业务 API 使用统一错误结构，至少包含错误代码、可读提示和请求标识；未认证为 401，已认证但越权为 403，资源不存在为 404。
- 列表必须按当前身份可见范围过滤；详情、下载、检索、引用跳转和 MCP 工具执行必须再次校验资源归属。
- 班级 ID 可以用于教师选择任教班级，但不能单独构成授权依据；学生不能通过修改参数切换到别班。
- 创建与更新操作要有重复提交处理；异步请求返回可查询的任务标识，而不是立即宣称已完成。
- 模型请求与响应保留脱敏审计信息，包括应用配置版本、提示词模板版本、检索片段 ID、工具调用 ID、耗时及错误类型；不记录密钥和完整敏感数据。

## 3. 关键接口组

| 接口组 | 预期行为 |
| --- | --- |
| 认证 | 登录、刷新、退出、当前身份；支持撤销已发令牌 |
| 材料 | 上传、列表、详情正文、版本、下载、索引状态、撤回；严格按班级授权 |
| 检索与问答 | 在授权材料范围检索，返回片段及来源；对话支持流式事件、引用和错误事件 |
| Agent/Skill/MCP | 配置、启停、测试与调用；工具执行前二次鉴权，未知工具不得执行 |
| 知识缺口 | 候选、归并、审核、补充、索引状态及前后对照 |
| 作业 | 模板、发卷、本人实例、提交、批改任务、复核及结果查看 |
| 周报 | 统计预览、草稿生成、编辑、审核、发布和撤回 |

## 4. 数据与安全底线

- 数据库使用迁移管理，业务记录不能靠容器重启后仍在内存来冒充持久化。
- 文件与索引中的班级归属一致；更新版本时先完成索引，再原子切换生效版本。
- 导出、下载和后台任务同样适用权限规则，不能绕过普通页面的检查。
- 测试中使用虚构账号和数据；外部模型仅接收经授权的必要片段，不发送整个知识库或未授权班级内容。
