# 数据模型与约束（规划版）

使用 PostgreSQL 保存业务事实，pgvector 保存材料片段向量，Redis 仅作任务队列/短期状态。本文是逻辑模型，不是迁移脚本。表名、字段类型与索引在实现 PR 中锁定。

## 1. 身份和班级

| 实体 | 核心字段 | 约束 |
| --- | --- | --- |
| `users` | ID、用户名、密码哈希、状态、创建时间 | 用户名唯一；不保存明文密码 |
| `classes` | ID、名称、状态 | A/B 为演示班级，不作为硬编码业务规则 |
| `memberships` | 用户 ID、班级 ID、角色、有效期 | 同一用户/班级/角色有效关系唯一；每次请求检查当前状态 |
| `refresh_tokens` | 令牌 ID 哈希、用户 ID、过期、撤销时间 | 支持退出与账号禁用后的撤销 |

## 2. 材料、检索与引用

| 实体 | 核心字段 | 约束 |
| --- | --- | --- |
| `materials` | ID、班级 ID、标题、活动版本 ID、撤回状态 | 班级归属不可由学生更改 |
| `material_versions` | ID、材料 ID、版本号、文件摘要、正文位置、索引状态、创建者/时间 | 版本内容不可变；同材料版本号唯一 |
| `material_chunks` | ID、版本 ID、序号、文本、页码/段落、向量、全文索引 | 片段与版本、班级一致；按班级与活动版本检索 |
| `citations` | ID、消息 ID、版本 ID、片段 ID、引用文本快照 | 历史引用不随新版本改写 |

索引状态至少包括草稿、解析中、索引中、生效、失败、撤回。活动版本切换使用事务与乐观并发检查；失败保留原活动版本。检索应有班级过滤、全文索引、向量索引和版本约束，RRF 的融合参数与 top-k 在应用配置版本中记录。

## 3. Agent、会话与工具

| 实体 | 核心字段 | 约束 |
| --- | --- | --- |
| `ai_apps`、`app_versions` | 班级、名称、发布状态、提示词/知识范围/工具绑定版本 | 改配置生成新版本，历史会话保留旧版本引用 |
| `skills`、`skill_versions` | 名称、来源、审核状态、版本、可用角色/班级 | 上传内容默认禁用，审核后才可启用 |
| `mcp_servers`、`tool_bindings` | 服务器配置引用、工具名、参数模式、允许范围、超时 | 凭据只引用密钥存储；工具白名单版本化 |
| `conversations`、`messages` | 用户、班级、应用版本、消息角色、序号、状态 | 用户仅访问本人会话；消息顺序可恢复 |
| `tool_calls` | `tool_call_id`、会话/消息、工具、脱敏参数、结果状态、耗时 | 调用与结果关联；错误可审计 |

## 4. 新增业务与教学事实

| 实体 | 核心字段 | 约束 |
| --- | --- | --- |
| `knowledge_gaps`、`gap_evidence`、`gap_reviews` | 班级、归并键、问题、热度、证据、审核状态 | 只在班级内归并；审核和回补记录不可覆盖 |
| `assignment_templates` | 班级、题目模板、参数规则、Rubric、开放时间 | 发布后保留不可变版本 |
| `assignment_instances` | 模板版本、学生 ID、参数、题目快照、答案快照、状态 | 学生与模板版本唯一或由明确重发规则管理；答案不返回学生 |
| `submissions` | 实例 ID、内容位置、提交时间、版本 | 学生仅提交本人实例；重复提交规则明确 |
| `grade_runs`、`grade_reviews` | 提交 ID、AI 建议分、依据、模型版本、教师最终分/理由 | AI 初评与最终分分开，历史批改不可覆盖 |
| `weekly_reports`、`report_facts`、`report_reviews` | 班级/周期、事实快照、AI 草稿、审核/发布状态 | 同一班级周期的版本可追踪；学生只读已发布 |
| `jobs`、`audit_events` | 任务类型、幂等键、状态、重试、错误；操作者、动作、对象 | 失败可诊断；审计脱敏且不可由普通用户改写 |

## 5. 数据完整性与保留

- 外键、唯一约束和事务保护必须由数据库承担；不能只靠前端校验。
- 所有可按班级查询的业务表保留班级关联或可验证的归属链；删除/撤回采用明确策略，不产生孤立引用。
- 文件名使用随机存储标识，数据库保存摘要、内容类型、大小与原名显示字段；下载按资源 ID 授权。
- 数据库迁移可前进且有回退/备份说明；迁移和种子数据分别执行，种子数据只允许演示/测试环境。
- 个人信息和审计记录的保留期限在真实部署前由小组与课程要求确定；未确定前不声称符合任何特定合规标准。
