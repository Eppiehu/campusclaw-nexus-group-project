# Spec Delta

## ADDED Requirements

### Requirement: 文字评分说明
系统 SHALL 保存教师撰写的评分说明，并让自动批改根据这段说明给出一个总分。

#### Scenario: 教师保存文字说明
- **WHEN** 教师创建或编辑草稿作业并提交一段评分说明
- **THEN** 系统保存这段文字，作业详情按原文展示，并说明由 AI 自行判断

#### Scenario: 提交旧的分项数组
- **WHEN** 教师提交由名称和分值组成的评分数组
- **THEN** 系统拒绝保存

#### Scenario: 截止后自动批改
- **WHEN** 作业已过截止时间并且存在待批改作答
- **THEN** 模型只收到评分说明、题目、标准答案和学生作答，并返回 0 到 100 的总分和评语

#### Scenario: 读取旧分项
- **WHEN** 作业里仍保存着改版前的分项数组
- **THEN** 系统不改写该作业，读取时只展示其中的项目名称
