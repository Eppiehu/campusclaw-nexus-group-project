# 变更：Linux 一键部署与健康验收

## 背景

当前脚本要求手工创建多个密钥，未等待服务健康；端口冲突或初始化失败后可能误以为部署成功。小组仓库需供老师在 Linux 上按文档复现。

## 范围

改造现有部署脚本，首次生成私有随机演示配置，执行 Docker/Compose/端口预检，依序构建、迁移、初始化和健康等待。更新 README 与 Linux 部署说明。保持现有 Compose 项目名、数据卷、业务 API、数据库结构和端口默认值不变。

## 验收

- 新主机运行一条命令后获得可用服务与虚构种子账号；配置不入库、不输出密码。
- 重复执行保持数据卷和幂等种子；端口冲突、构建失败、迁移失败或 API 不健康时返回非零状态。
- 只对隔离环境实测；原网站和旧 Nexus 的服务、卷、入口不受部署脚本操作。
