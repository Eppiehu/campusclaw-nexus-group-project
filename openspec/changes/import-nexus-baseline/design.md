# 设计：最小可审查的实现导入

采用代码快照而非合并个人仓库历史，避免把课程报告、PDF、截图、真实部署数据或单人历史提交写入小组贡献记录。复制必要的 Nexus 模块和测试，并在 PR 中标明来源提交。后端入口仅导出 Nexus Flask 工厂；前端由镜像构建，公开 Embedding 模型在镜像构建时下载并在运行时离线使用。Compose 使用独立项目名，数据库与 Redis 仅在内部网络。运行配置从不含密钥的模板复制到本地文件。

本变更不宣称完成小组目标架构。Vue Router/Pinia、令牌刷新、API/环境变量统一、安全脚本、性能和 HTTPS 由后续 OpenSpec 变更处理。独立 Linux 容器验收是合并后的交付门槛；无法运行时记录 NOT RUN。
