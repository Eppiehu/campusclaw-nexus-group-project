# 设计

运维通过 `NEXUS_MCP_SERVERS` JSON 登记服务器别名、Streamable HTTP URL、`credential_ref`、允许班级和工具名白名单。默认只接受 HTTPS 公网地址，拒绝重定向；显式隔离测试开关才接受回环 HTTP。教师不能创建任意网络目标，也不能指定进程命令。凭据只从环境变量读取，不能存入数据库或返回前端。

`mcp_connections` 保存班级、名称、服务器别名、凭据引用、测试状态、工具模式快照和配置指纹；复用 `agents.tools` 保存命名空间工具名（`ext_<连接ID>__<工具名>`），无需新增应用字段。连接测试列举工具，与运维白名单求交并验证 JSON Schema；拒绝引用和正则模式以避免校验时额外联网或不受控正则执行。测试失败立即失效，不泄漏远端错误。配置变化使旧快照失效。教师可停用连接，调用时立即生效。

现有五个内置工具保持 stdio 和服务端二次鉴权。外部工具使用 SDK Streamable HTTP，在每次调用前重新解码 JWT 并查询应用、连接和班级；模型只提供业务参数，不能扩大绑定。外发只包含该工具参数以及服务端生成的最小班级/角色/用户上下文头，不发送本地 JWT、知识库、对话或模板。运维登记的外部服务必须根据班级专用凭据及上下文实现自身的数据隔离；本地应用不能替第三方实现其内部资源授权。

工具结果限制长度并按 tool_call_id 返回；调用审计仅记录工具、调用ID、成功与否，不记录凭据或参数/结果原文。连接超时、远端错误及非授权工具均可读失败，不伪装成功。迁移只新增表和 JSON 字段，降级通过备份恢复。
