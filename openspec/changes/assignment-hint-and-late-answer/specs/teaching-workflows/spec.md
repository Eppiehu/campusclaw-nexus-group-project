# Spec Delta

## ADDED Requirements

### Requirement: 截止后公布评分规则和参考答案
系统 SHALL 在作业截止前向学生隐藏评分规则和题目参考答案，并在截止后只向该学生公布其自己题目的参考答案和评分规则。

#### Scenario: 截止前学生查看作业
- **WHEN** 学生在截止时间之前读取已发布作业和自己的试卷
- **THEN** 响应包含作答提示，不包含评分规则、服务端答案表达式和参考答案

#### Scenario: 截止后学生查看作业
- **WHEN** 学生在截止时间之后读取已发布作业和自己的试卷
- **THEN** 响应包含评分规则和该试卷的参考答案，仍不包含服务端答案表达式

### Requirement: 作答提示不参与评分
系统 SHALL 保存教师填写的作答提示，让学生在作答时查看，并且不得把这段提示交给自动批改。

#### Scenario: 教师保存作答提示
- **WHEN** 教师创建或编辑作业并填写作答提示
- **THEN** 系统保存这段文字，学生在截止前就能读到

#### Scenario: 自动批改
- **WHEN** 系统为已截止的作答请求模型评分
- **THEN** 模型收到的材料只有题目、标准答案、学生作答和评分说明
