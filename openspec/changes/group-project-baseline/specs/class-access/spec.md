# Spec Delta

## Purpose

定义教师与学生在班级、个人资源和工具调用中的服务端授权行为，确保所有访问路径遵守同一隔离边界。

## ADDED Requirements

### Requirement: 身份与班级授权
系统 SHALL 从已验证身份与服务端成员关系确定角色和班级范围，不能把客户端提交的角色或班级字段作为授权依据。

#### Scenario: 未登录访问受保护资源
- **WHEN** 未登录请求材料、会话、作业或报告接口
- **THEN** 系统返回未认证状态，且不返回受保护正文

#### Scenario: 跨班访问
- **WHEN** A 班用户修改资源 ID 或请求参数访问 B 班材料、检索、下载或 MCP 工具
- **THEN** 服务端拒绝访问，且 B 班内容不进入模型请求

### Requirement: 学生个人资源隔离
系统 SHALL 限制学生仅访问自己的题目实例、提交、成绩、错题和会话。

#### Scenario: 读取同班他人作业
- **WHEN** 学生请求同班另一名学生的作业实例或成绩
- **THEN** 服务端拒绝访问并记录可审计的授权结果

### Requirement: 令牌生命周期
系统 SHALL 验证 JWT 有效期与签名，并支持账号停用或退出后的令牌撤销。

#### Scenario: 使用过期或已撤销令牌
- **WHEN** 客户端携带过期、伪造或已撤销的令牌访问业务 API
- **THEN** 系统拒绝请求且不返回受保护数据
