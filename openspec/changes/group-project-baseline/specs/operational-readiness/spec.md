# Spec Delta

## Purpose

定义老师在独立 Linux 环境可复现运行和验收项目的条件，覆盖容器部署、安全自动化、并发容量与虚构数据。

## ADDED Requirements

### Requirement: Linux 容器冷启动
系统 SHALL 提供可复现镜像、Docker Compose 编排、环境变量示例、迁移、健康检查与持久化说明。

#### Scenario: 干净 Linux 主机验收
- **WHEN** 老师在仅预装 Docker Engine/Compose 的 Linux 主机按文档执行部署
- **THEN** 服务可构建并启动，`/health` 返回 200，虚构账号可完成主流程，重启后数据仍在

### Requirement: 安全自动化测试
系统 SHALL 提供默认只连接隔离测试环境的自动化安全测试，覆盖认证、班级、文件和 MCP 边界。

#### Scenario: 误指向生产环境
- **WHEN** 测试脚本配置为公网或非测试数据库
- **THEN** 脚本拒绝执行，不修改目标数据

#### Scenario: 安全测试失败
- **WHEN** 未登录、跨班、令牌、上传、下载、检索或工具越权测试失败
- **THEN** 结果标为 FAIL，CI 阻止合并并保留可定位的脱敏证据

### Requirement: 并发容量有实测结论
系统 SHALL 在指定 Linux 机器按 20/50/100/200 并发分级测试业务 API、检索、SSE 和后台任务，并记录延迟、吞吐、错误率与资源占用。

#### Scenario: 达到暂定容量目标
- **WHEN** 普通只读 API 在 100 并发下实测 p95 不高于 2 秒、服务端错误率低于 1%，且无权限串漏
- **THEN** 该机器与配置可标为达到 100 并发目标；更高并发须另报实际结果

### Requirement: 可重复的虚构种子数据
系统 SHALL 提供幂等初始化的 A/B 班、教师/学生、材料、Agent、作业、评分与周报演示数据，不包含真实学生资料或公开密码。

#### Scenario: 重复初始化
- **WHEN** 在演示环境重复运行初始化
- **THEN** 不产生重复账号或资源，教师和学生仍可按预期验收班级隔离及核心流程
